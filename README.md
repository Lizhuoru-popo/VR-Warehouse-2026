## 📖 项目概述

本项目以**智慧仓储环境管理**为应用背景，综合运用 MQTT 消息通信、Unity 三维可视化、虚拟现实交互与数字孪生等技术，构建了一套面向仓储环境监测与异常处置的 **VR 智慧仓储原型系统**。

系统通过模拟环境传感器产生温度、相对湿度及 CO₂ 等监测数据，利用 MQTT 协议实现数据的实时传输，并在 Unity 构建的虚拟仓储环境中进行三维空间化呈现。当监测数据偏离预设环境条件时，系统通过**三级状态机制**识别异常，结合三维空间位置对异常传感器进行突出显示，辅助使用者快速发现异常区域；用户可进一步通过 VR 交互选择相关设备并执行控制操作，使模拟环境进入恢复状态，从而形成完整的业务闭环：

**环境监测 → 异常识别 → 空间定位 → 设备处置**

## 🏭 应用场景

系统模拟三类典型仓储环境，各仓储区域设置具有空间位置的环境传感器，对温度、湿度等参数进行实时监测：

| 仓储区域 | 主要监测参数 | 主要联动设备 | 应用定位 |
|---------|-------------|-------------|---------|
| 冷冻肉类仓 | 温度、相对湿度 | 制冷设备、除湿设备 | 冷冻食品环境监测 |
| 苹果保鲜仓 | 温度、相对湿度、CO₂ 浓度 | 制冷设备、通风设备 | 果蔬冷藏环境监测 |
| 巧克力恒温仓 | 温度、相对湿度 | 空调设备、除湿设备 | 恒温、干燥环境监测 |

## ✨ 核心功能

- **仓储场景展示**：三个具有不同环境条件的虚拟仓储区域，涵盖仓库、货物、传感器及相关设备的空间布局
- **环境数据监测**：实时接收并展示各传感器的温度、相对湿度及 CO₂ 等参数
- **状态识别与异常提示**：依据三级阈值对环境状态进行分类（正常 / 预警 / 异常），通过界面提示和空间高亮体现异常程度
- **VR 空间交互**：支持在虚拟仓储环境中移动、选择传感器并查看对应监测信息，实现监测数据与空间位置的关联
- **设备联动处置**：针对异常环境，通过 VR 交互选择相关设备并执行控制操作，使模拟环境进入恢复状态，并在后续监测数据中体现处置结果
- **综合状态展示**：对仓储区域及传感器的总体状态进行汇总展示，便于快速掌握系统运行情况

## 🌡️ 环境监测三级阈值

系统依据储存对象的保存条件将环境状态划分为正常（NORMAL）、预警（WARNING）和异常（ABNORMAL）三个等级。阈值参考 GB 2707-2016《食品安全国家标准 鲜（冻）畜、禽产品》、GB/T 30134-2025《冷库管理规范》、GB/T 40960-2021《苹果冷链流通技术规程》、GB 17403-2016《食品安全国家标准 糖果巧克力生产卫生规范》等国家标准：

| 仓储区域 | 参数 | NORMAL | WARNING | ABNORMAL | 单位 |
|---------|------|--------|---------|----------|------|
| 冷冻肉类仓 | 温度 | -25 ~ -18 | -18 ~ -15 | > -15 | ℃ |
| | 相对湿度 | 90 ~ 95 | 85~90 或 95~98 | <85 或 >98 | %RH |
| 苹果保鲜仓 | 温度 | -1 ~ 1 | -2~-1 或 1~3 | <-2 或 >3 | ℃ |
| | 相对湿度 | 85 ~ 95 | 80~85 或 95~97 | <80 或 >97 | %RH |
| | CO₂ 浓度 | 0 ~ 1.0 | 1.0 ~ 2.0 | > 2.0 | % |
| 巧克力恒温仓 | 温度 | 18 ~ 20 | 15~18 或 20~23 | <15 或 >23 | ℃ |
| | 相对湿度 | 45 ~ 55 | 55 ~ 65 | > 65 | %RH |

## 🛠️ 技术架构

系统总体采用 **「模拟数据源 → MQTT 通信 → 业务处理 → VR 数字孪生展示 → 设备联动」** 的实施架构：

| 模块 | 技术 | 职责 |
|------|------|------|
| 数据源 | Python 传感器模拟器（`Tools/sensor_simulator.py`） | 生成仓储环境监测数据，并根据控制指令切换模拟状态 |
| 通信层 | MQTT | 承担监测数据与设备控制信息的双向消息传输 |
| 业务逻辑 | 状态判定模块 | 对监测数据进行三级阈值判断与状态汇总，向展示层提供处理后的环境状态信息 |
| 展示层 | Unity + VR | 数字孪生场景构建、VR 空间交互和信息可视化展示 |

## 🚀 快速开始

### 环境要求

- Unity（URP 渲染管线）
- Python 3.x
- MQTT Broker（如 EMQX / Mosquitto）
- VR 设备（PICO）

### 运行步骤

1. 克隆仓库：

   bash
   git clone [https://github.com/Lizhuoru-popo/VR-Warehouse-2026.git](https://github.com/Lizhuoru-popo/VR-Warehouse-2026.git)
   
2.启动 MQTT Broker 服务

3.运行 Python 传感器模拟器：bash  cd Tools   python sensor_simulator.py   

4.使用 Unity Hub 打开项目根目录，进入主场景运行，或部署至 VR 一体机体验
