========================================
  传感器模拟器使用说明
========================================


【快速开始】

1. 环境要求
   - Python 3.x
   - 依赖：paho-mqtt

2. 安装依赖
   pip install paho-mqtt

3. 启动模拟器
   在项目根目录下运行：
   python -u Tools/sensor_simulator.py


========================================
  传感器列表
========================================

仓库               传感器ID        参数
--------------    -----------    --------------------
frozen_meat       L01, M01, R01  temperature, humidity
  (冷冻肉)
apple             L02, M02, R02  temperature, humidity, co2
  (苹果)
chocolate         L03, M03, R03  temperature, humidity
  (巧克力)


========================================
  状态模式
========================================

normal_data     正常数据
warning_data    预警数据
abnormal_data   异常数据


========================================
  命令大全
========================================


1. 查看状态
   ----
   命令：状态  或  list
   说明：显示所有传感器当前的模拟状态

   示例：
   > 状态


2. 设置单个传感器的单个参数
   ----
   命令：模式 <仓库> <传感器ID> <参数> <状态>
         或 mode <仓库> <传感器ID> <参数> <状态>

   示例：
   > 模式 apple L02 temperature abnormal_data
     （将苹果仓库 L02 传感器的温度设为异常）

   > 模式 frozen_meat M01 humidity warning_data
     （将冷冻肉仓库 M01 传感器的湿度设为预警）


3. 批量设置（整个仓库的某个参数）
   ----
   命令：联动 <仓库> <参数> <状态>

   示例：
   > 联动 apple temperature abnormal_data
     （将苹果仓库所有传感器的温度设为异常）

   > 联动 chocolate humidity warning_data
     （将巧克力仓库所有传感器的湿度设为预警）


4. 恢复单个传感器
   ----
   命令：恢复传感器 <仓库> <传感器ID>

   示例：
   > 恢复传感器 apple L02
     （将苹果仓库 L02 传感器的所有参数恢复正常）


5. 恢复整个仓库
   ----
   命令：恢复仓库 <仓库>

   示例：
   > 恢复仓库 apple
     （将苹果仓库所有传感器的所有参数恢复正常）


6. 退出
   ----
   命令：退出  或  exit


========================================
  MQTT 说明
========================================

Broker   : broker.emqx.io
Port     : 1883
发布主题 : 23VRteamA/sensor/{仓库}/{传感器ID}
订阅主题 : 23VRteamA/control/#

控制指令：
当收到 23VRteamA/control/{仓库}/{设备} 的控制指令且 IsOn=true 时，
该仓库的所有传感器自动恢复为 normal_data。


========================================
  数据格式
========================================

发布的 JSON 数据：

{
  "sensor_id": "L02",
  "warehouse": "apple",
  "temperature": 0.45,
  "humidity": 90.23,
  "co2": 0.56,
  "timestamp": 1234567890
}

注意：只有苹果仓库（apple）包含 co2 字段。


========================================
  常见问题
========================================

Q: 启动后一直没输出？
A: 检查网络连接，确认能访问 broker.emqx.io。

Q: Unity 收不到数据？
A: 1. 确认 MQTTManager 的 broker 地址和端口一致
   2. 确认订阅主题是 23VRteamA/#
   3. 检查传感器 GameObject 上的 sensorId 和 warehouse
      是否与模拟器对应

Q: 如何测试异常效果？
A: 输入 "联动 apple temperature abnormal_data"，
   然后看 Unity 中苹果仓库的传感器是否变红。
